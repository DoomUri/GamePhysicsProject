# GamePhysicsProject

Research project exploring the application of physics principles, mainly kinematics, in video games and simulations. Includes theoretical analysis and five physics simulators developed from scratch using HTML, CSS, and JavaScript.


# Repository Structure

The repository is organized into two main folders:

· Documentation/: Contains all the theoretical research, including explanations of the physics principles studied and the learning process of the programming languages and graphical environments used throughout the project. It also includes an appendix with images and demonstrations.

· Code/: Contains all the source code for the five physics simulators. Each simulator is developed using HTML, CSS, and JavaScript.

# Running the Simulators

No installation or additional setup is required to run the simulators. Simply open the corresponding .html file in any modern web browser to interact with the simulation.
